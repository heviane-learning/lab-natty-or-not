# Prompt Log

Este diretório registra o processo de criação, análise e refinamento dos prompts usados no projeto.

O objetivo é manter um histórico claro do raciocínio, das ideias, das melhorias aplicadas e dos resultados obtidos ao trabalhar com inteligência artificial generativa.

## Objetivo

Documentar o ciclo completo de uso da IA para:

- contextualizar o projeto
- formalizar a solicitação inicial
- analisar a resposta da IA
- identificar pontos de melhoria
- refinar o prompt
- registrar a versão final

## Estrutura sugerida

```text
prompts/
├── README.md
├── 001-solicitacao-inicial.md
├── 002-analise-ia.md
├── 003-prompt-refinado.md
├── 004-resposta-refinada.md
├── 005-prompt-final.md
├── 006-notas-de-analise.md
└── 007-resultado-entregavel.md
```

## Convenção de nomenclatura

Os arquivos devem seguir uma sequência numérica para facilitar a leitura cronológica:

- `001-...` = solicitação inicial
- `002-...` = análise da IA
- `003-...` = refinamento do prompt
- `004-...` = resposta revisada
- `005-...` = prompt final
- `006-...` = observações e aprendizados
- `007-...` = material final ou entrega

## Template recomendado para cada arquivo

Cada prompt ou resposta pode ser registrado com o seguinte formato:

```markdown
# Título

## Data
DD/MM/AAAA

## Objetivo
Descreva o que a IA deveria ajudar a fazer.

## Contexto
Informe o cenário, o projeto, o público e o tema.

## Prompt
Copie aqui o texto exato enviado para a IA.

## Resposta da IA
Registre a resposta principal, destacando pontos importantes.

## Análise crítica
Liste:
- pontos fortes
- pontos fracos
- oportunidades de melhoria
- ajustes necessários

## Refinamento
Descreva como o prompt foi ajustado.

## Resultado
Indique se o prompt foi aprovado, adaptado ou descartado.
```

## Boas práticas para manter este log

- Registre o prompt original antes de alterar qualquer coisa.
- Preserve a resposta da IA em texto bruto ou com pouca edição.
- Documente os ajustes por motivo e não apenas por acidentalidade.
- Inclua o modelo usado, quando relevante.
- Mantenha a evolução em ordem cronológica.
- Registre o que funcionou e o que não funcionou.
- Use linguagem clara e objetiva.

## Exemplo de log de evolução

```markdown
1. Prompt original
2. Resposta inicial da IA
3. Problemas identificados
4. Ajustes aplicados
5. Novo prompt
6. Nova resposta
7. Melhorias implementadas
8. Resultado final
```

## Uso do diretório

Este diretório funciona como um diário de engenharia de prompts. Ele ajuda a:

- repetir boas práticas
- aprender com erros e acertos
- documentar a evolução do processo
- preparar um portfólio mais profissional e transparente
- demonstrar o raciocínio por trás das decisões criativas e técnicas

## Importante

O objetivo não é apenas salvar respostas da IA, mas registrar o processo de pensamento e a lógica do refinamento. Esse histórico é tão importante quanto o resultado final.
