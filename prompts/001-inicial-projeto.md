# Prompt Inicial: Concepção do projeto

## Objetivo

Explicar sobre o projeto, o desáfio proposto e a ideia inicial de entregavél.
Criar contexto, as primeiras regras e a documentação inicial para guiar os agentes de IA.

## Prompt

```prompt
Este é o repositório https://github.com/digitalinnovationone/lab-natty-or-not do curso 'Natural ou Fake Natty? Como Vencer na Era das IAs Generativas' da DIO. Ele é um template para que eu faça um fork e desenvolva o meu projeto a partir dele. O objetivo deste repositório, além de ser o entregavél do curso, é ser um portifólio profissional para o aluno e uma documentação rica sobre o uso de inteligência artificial generativa na criação de conteúdo digital.

Mais especificamente preciso demonstrar o meu processo de criação de conteúdo assistido por IA, documentando a reflexão crítica e o resultado final. O entregável esperado inclui um README com registro do projeto e com os entregáveis, como por exemplo e-book, vídeo, podcast, etc.

Resumindo, o fluxo típico é: escolher um formato de conteúdo, usar IA para roteirizar e criar o material, documentar o processo e apresentar um resultado final.

Minha proposta inicial é a criação de um e-book:

- Tarefa 1: Definição do tema 
- Tarefa 2: Criação das imagens
- Tarefa 3: Seleção das ferramentas
- Tarefa 4: criação do e-book

Obs: Após a conclusão da etapa "e-book", penso em avançar com um video promocional com avatar, e depois um podcast.

Análise críticamente, forneça feedback com sugestões de melhorias e retorne em formato markdown.
```
