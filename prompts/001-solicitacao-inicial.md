# Engenheiro de Prompts

## Solicitação inicial para refinamento

Comporte-se como um engenheiro de prompts. 
Analise o prompt abaixo, ele será usado para iniciar um projeto assistido por ia.
Me ajude a melhorar para obter melhores resultados, de acordo com as boas práticas e técnicas atuais de mercado.

Segue o prompt: "Este é o repositório https://github.com/digitalinnovationone/lab-natty-or-not do curso 'Natural ou Fake Natty? Como Vencer na Era das IAs Generativas', ele é um template para criar um 'case' de conteúdo artificialmente realista, usando ferramentas de IA para produzir algo que pareça natural, mas foi assistido por inteligência artificial. O tipo de entrega esperado é conteúdo gerado com IA, pautado em descrição, tecnologias utilizadas, processo, resultados e reflexão. Este é o repositório https://github.com/heviane-learning/lab-natty-or-not, que eu criei (fork) para ser o entregável do projeto.

Entregável esperado:
README com registro do projeto/portfólio, documentando o processo e a reflexão crítica.
Portfólio com materiais como e-book, podcast, vídeo ou avatar, etc.

Resumindo, o fluxo típico é: escolher um formato de conteúdo, usar IA para roteirar/criar, documentar o processo e apresentar um resultado final.

Pensei em um projeto hibrido (e-book + capa + vídeo promocional com avatar).
Pensei na seguinte divisão de tarefas para execução:

Tarefa 1: Escolha do tema + Escolha da imagem de capa
Tarefa 2: Escolha das ferramentas
Tarefa 3: Criação do e-book
Tarefa 4: Criação do vídeo promocional com avatar

O que acha? Análise e forneça feedback com sugestões de melhorias se necessário."
